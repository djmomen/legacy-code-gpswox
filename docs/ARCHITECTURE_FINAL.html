② نموذج العملاء (مثل GPSWOX)

قاعدة بيانات واحدة مشتركة، والعزل بالملكية لا بقاعدة منفصلة — مع شجرة موزّعين وخطط لكل حساب. مستخلص من كود GPSWOX الفعلي (User.manager_id، billing_plan_id، user_device_pivot).

Super Admin                         # يرى الكل
   └─ Reseller / Manager            # manager_id — يدير عملاءه
        └─ Customer (Account)       # owner_id — يملك الأجهزة والبيانات
             ├─ billing_plan        # خطة SaaS + devices_limit + subscription
             └─ Sub-user (Client)   # وصول مقيّد/مشاهدة
المفهومالآليةمصدره في GPSWOX
عزل البياناتكل سجل يحمل owner_id؛ global scope يفرض الفلترة على كل استعلامuser_device_pivot.user_id
هرمية الموزّعينحساب يرجع لنفسه عبر manager_id (شجرة)User.manager()
الخطط والحدودخطة SaaS لكل حساب: حد الأجهزة، انتهاء الاشتراكbilling_plan_id, devices_limit, subscription_expiration
الحسابات الفرعيةClient تابع لحساب، بصلاحيات مقيّدةClient → user()
تمييز مهم: «الخطط» هنا = خطط اشتراك SaaS (حدود أجهزة، تجديد) — وليست فوترة إيجار المركبات التي حذفناها. ثلاث طبقات وصول: مشرف → موزّع → عميل (+ مستخدم فرعي).

④ MVCS مع DDD + Clean + Hexagonal

أنماط غير متنافسة — كل واحد يجيب على سؤال مختلف. MVCS ينظّم طبقة التسليم، والبقية تنظّم القلب.

React (View)
   → Django URL/View      # Controller (MVCS) — HTTP فقط، رفيع
      → TrackingService    # Service (MVCS) — ينسّق + يفرض owner_id scope
         → UseCase         # Application (Clean) — Command/Query
            → Entity       # Domain/Model (DDD) — قواعد العمل
            → Port         # Hexagonal — interface (Traccar/LLM/Forecast)
               → Adapter   # Infrastructure — التنفيذ الفعلي

⑤ طبقة الذكاء

🤖 Flue — AI Runtime

خدمة TS مستقلة تنسّق الـ agents (sessions/tools/skills/sandbox/durability). يكلّمها Django عبر AIAgentPort.

🔀 LiteLLM — Router

proxy موحّد محايد للّغة: GPT/Gemini/Claude + fallback + تتبّع تكلفة + حدود لكل عميل.

🧠 المعرفة الهجينة

Surya OCR + vector RAG للملفات غير المنظّمة (PDF/صور) + OKF/MD للمعرفة المنسّقة، خلف KnowledgePort.

📈 TimesFM — التنبّؤ

تنبؤ بالصيانة/الوقود/الـ ETA/الاستخدام من TimescaleDB، يغذّي الـ agents.

🛡 ClawPatrol — الأمان

جدار أفعال وقت التشغيل: يوقف الأفعال الخطرة، يرسلها لموافقة بشرية، يسجّل كل شيء.

⑦ التوسّع (براغماتي)

ابقَ على Modular Django. فكّ خدمة مستقلة فقط عند ظهور عَرَض فعلي:

العَرَضالإجراء
ضغط ingestion يخنق الباقياستخرج tracking-svc (FastAPI/Go) + Kafka
تقارير ثقيلة تبطّئ الكتابةCQRS Read Models / projections منفصلة
تضارب deployments بين فِرقفكّ السياق المعني إلى خدمة مستقلة
حِمل AI/تنبؤ عالٍتوسعة أفقية لـ ai-layer و forecasting workers
لا microservices كاملة، ولا Istio، ولا Event Sourcing مبكرًا — تُضاف فقط عند الحاجة الفعلية. TimescaleDB وناقل الأحداث وLiteLLM جاهزة من البداية لأنها رخيصة وتدفع لاحقًا.
