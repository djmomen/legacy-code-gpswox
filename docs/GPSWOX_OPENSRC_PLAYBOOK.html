GPSWOX × opensrc — دليل تعدين الخبرة

وصفات جاهزة لتعدين كود GPSWOX بـ opensrc واستخراج معرفة الدومين لإعادة بنائها في Python

الإعداد

opensrc يجلب الكود المصدري لأي ريبو محليًا ليقرأه الـ agent. اجلب GPSWOX مرة واحدة:

npx opensrc path github:djmomen/legacy-code-gpswox   # يطبع مسارًا محليًا مخبّأً في ~/.opensrc/

# خزّن المسار في متغيّر واستخدمه في أي أمر:
GW=$(npx opensrc path github:djmomen/legacy-code-gpswox)
rg "fuel" "$GW/Tobuli/Sensors"     # ابحث في الكود
cat "$GW/config/tracker.php"        # اقرأ ملفًا
طريقة العمل: لكل وصفة أدناه: الهدف ما تريد فهمه · أوامر التعدين · استخرج ما تأخذه · Python أين يذهب. أعطِ هذا الملف للـ agent (في Spec Kitty/Claude Code) ليتبع الوصفات.

① ربط Traccar الهدف

افهم كيف تتدفّق البيانات من الأجهزة عبر Traccar إلى الأعمال.

cat "$GW/config/tracker.php"                          # إعداد Traccar: المنافذ، DB، Redis
cat "$GW/Tobuli/Entities/TraccarDevice.php"          # مرآة حالة الجهاز (uniqueId=IMEI)
rg "traccar_device_id|traccar" "$GW/Tobuli/Entities/Device.php"
cat "$GW/Tobuli/Entities/TrackerPort.php"            # منافذ البروتوكولات
ls "$GW/Tobuli/Protocols/Protocols"                  # 44 بروتوكول
استخرج
  • المنافذ القياسية لكل بروتوكول، ربط devices.traccar_device_id، حقول الحالة اللحظية، آلية registerUnknown.
Python
  • tracking/infrastructure/traccar_adapter.py (REST/WS/Forwarding خلف TraccarPort).

② تقسيم قواعد المواقع الهدف

cat "$GW/Tobuli/Services/DatabaseService.php"        # التقسيم الديناميكي
rg "user_database_pivot|database{|HasManyTable" "$GW/Tobuli"
cat "$GW/Tobuli/Entities/TraccarPosition.php"
استخرج
  • كيف يُسنَد المستخدم لقاعدة مواقع، بنية جدول-لكل-جهاز، استراتيجية الاحتفاظ.
Python
  • TimescaleDB hypertable واحد بـ owner_id + retention/compression (بدل التقسيم اليدوي).
